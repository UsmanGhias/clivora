# Security Policy

CLIVORA takes the security of our platform and user data seriously. This document describes our vulnerability disclosure process and security commitments.

## Supported Versions

Only the latest release on the `main` branch and current production builds distributed via Google Play are supported with security updates.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| Google Play v5.x | :white_check_mark: |
| < 5.0.0          | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in CLIVORA:

1. **Do not create a public GitHub issue.**
2. Send an email to **security@clivora.io** (or reach out via https://usmanghias.co.uk/contact).
3. Include detailed reproduction steps, target component, impact assessment, and proof of concept.

### Our Commitment
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an initial assessment and timeline for remediation.
- Once fixed, we will credit responsible security researchers in release changelogs.
