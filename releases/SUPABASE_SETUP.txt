HOW SYNC WORKS
--------------
1. User signs in (Firebase + mirrored Supabase session)
2. Profile upserted to `profiles`
3. Freelancer saves project → `project_shares`
4. Messages → `client_messages`
5. Client on another phone (same email) sees realtime updates
