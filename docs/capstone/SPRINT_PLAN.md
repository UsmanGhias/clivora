**Start:** 20 August 2026  

| Sprint | Dates (planned) | Goal | Exit demo (to PO) |
|---|---|---|---|
| 1 | 20 Aug – 17 Sep 2026 | Grader-ready repo: docs, board, secrets hygiene, unit tests, CI | Screen recording: README links + tests passing locally/CI |

Sprint planning happens at the start of each sprint using [USER_STORIES.md](./USER_STORIES.md) and the GitHub Project. Stories not in the sprint stay in the product backlog.

## Definition of done (every story)

- Code on `main` (or PR into `main`) in `UsmanGhias/clivora`
- Tests added or updated when behavior is testable
- Board card moved to Done
- No secrets committed
- Baseline features not rewritten “as new Capstone work”
