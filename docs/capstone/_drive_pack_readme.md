## Presenting on another laptop

1. Unzip.
2. Open `01-Presentation/CLIVORA-MSSE-Capstone.pptx` (or the PDF if fonts look wrong).
3. Install the files in `01-Presentation/fonts/` if PowerPoint does not show Inter.
4. Keep `01-Presentation/SPEAKER_NOTES.md` open while you record.

Do **not** upload this zip (or the PPTX) as the Quantic “presentation”. That field wants the Drive **video** `.mp4`.
