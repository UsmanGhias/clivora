# Recording and file rules (presentation rubric)

Quantic requires **one** video, 15–20 minutes, all members on camera, government ID shown.

## File

1. One file: `.mp4` preferred (`.mov` OK). Not PowerPoint, PDF, ZIP, or per-slide clips.
2. Host on **Google Drive** → Anyone with the link can view.
3. You are visible and audible; screen share of the working app is clear.

## ID check

Hold a government-issued ID to the camera so **name and photo** are readable. Then continue the demo from [DEMO_SCRIPT.md](./DEMO_SCRIPT.md).
